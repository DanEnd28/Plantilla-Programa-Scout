📖 GUÍA DE USO

Esta página no se imprime

✏️ Editar

Clic en Editar. Todos los campos se resaltan en naranja. El nombre de la actividad y la ambientación son editables directamente en su posición. Auto-guarda cada 45s.

📋 Programa

Con Editar activo: clic en cualquier celda para editar. Arrastra ☰ para reordenar filas. Las horas se recalculan automáticamente.

📅 Multi-día

En Config activa "Multi-día". Define fechas de inicio y fin. Si son días distintos, el programa se divide automáticamente en secciones por día, cada una con su propia hora de inicio.

⚙️ Config

Nombre del grupo, rama (cambia colores y logo), horario, fechas, responsable, código. El código se genera como DDMMAA-R si se deja vacío.

💾 HTML

Embebe todos los datos e indicadores en el archivo. Los indicadores extras quedan en el const INDICADORES permanentemente. Al reabrir, todo está igual.

🗑️ Reset

Limpia localStorage. Indicadores cargados y logos default se conservan. Ofrece descargar HTML/PDF antes de borrar.

🎨 COLORES POR RAMA

Al inicio del CSS hay un bloque .rama-manada, .rama-tropa, etc. Edita los hex de cada bloque para cambiar todos los colores de esa rama:

.rama-manada {
  --cm:    #c8a800;  /* principal   */
  --hdr-a: #3a2c00;  /* header inicio */
  --hdr-b: #c8a800;  /* header fin  */
}

📊 INDICADORES — OTRAS RAMAS

Manada y Tropa ya embebidos. Para Comunidad y Clan importa un JSON y haz 💾 HTML.

{ "comunidad": { "Carácter": { "E1": ["..."], "E2": ["..."] } } }
